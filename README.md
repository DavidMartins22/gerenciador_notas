# Sistema de Gerenciamento de Notas

## Descrição do Projeto

Este projeto consiste em um sistema simples de gerenciamento de notas de estudantes, desenvolvido em Python. O sistema permite armazenar dados acadêmicos, calcular médias, verificar aprovação dos estudantes e gerar relatórios de desempenho.

O objetivo principal do projeto é aplicar conceitos fundamentais de programação, como estruturas de dados, modularização, funções, controle de fluxo, documentação com docstrings e boas práticas seguindo o padrão PEP 8.

---

## Funcionalidades

- Cadastro de estudantes
- Armazenamento de notas
- Cálculo automático de médias
- Verificação de aprovação ou reprovação
- Geração de relatórios acadêmicos
- Organização do código em funções independentes
- Testes básicos de validação

---

## Tecnologias Utilizadas

- Python 3

---

## Como Executar o Sistema

1. Abra o terminal na pasta do projeto.

2. Execute o arquivo principal com o comando:
```bash
python gerenciador_notas.py
```
3. O sistema exibirá os relatórios e informações dos estudantes no terminal.

---

## Como Executar os Testes

1. Abra o terminal na pasta do projeto.

2. Execute o arquivo de testes com o comando:
```bash
python test_notas.py
```
3. Os testes verificarão se as funções de cálculo de média e aprovação estão funcionando corretamente.

- gerenciador_notas.py → Arquivo principal do sistema
- test_notas.py → Arquivo responsável pelos testes
